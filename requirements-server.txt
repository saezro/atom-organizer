# Dependencias del pipeline SIN interfaz, para el contenedor del Cloud Run Job.

# No es requirements-linux.txt menos cosas al tuntún: esa lleva PySide6, shiboken,
# pyinstaller, ipykernel y jupyter, que en un contenedor que no pinta nada ni
# construye nada son ~400 MB de imagen y superficie de dependencias a mantener.
# Aquí solo está lo que el pipeline importa de verdad (atom_core, pipeline, exif,
# utils). Las transitivas (dateutil, pytz, six, fonttools…) las resuelve pip.
#
# Las versiones se mantienen clavadas a las de requirements-linux.txt: el
# contenedor debe procesar el vuelo EXACTAMENTE igual que el escritorio, y una
# numpy distinta ya es una diferencia numérica que nadie va a estar buscando.
# Qt NO está y no debe volver. Las fases del pipeline vivían dentro de la clase
# Qt `MainWindow`, así que importar el pipeline importaba PySide6: ~400 MB de
# imagen por una dependencia que el contenedor no usa para nada visible. Ahora
# viven en `atom_core/phases.py`, sin Qt, y de ahí las heredan tanto la GUI como
# el host headless. `tests/test_pipeline_sin_qt.py` importa `atom_core.organize`
# con PySide6 vetado: si alguien reintroduce el acoplamiento, CI lo para antes
# de que la imagen vuelva a engordar.
